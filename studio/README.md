# Publimetal Studio

Sanity Studio para administrar proyectos de Publimetal.

## Desarrollo local

```bash
npm install
npm run dev
```

El Studio se abre por defecto en `http://localhost:3333`.

## Configuración

- Project ID: `t3wmz9p4`
- Dataset: `production`
- Tipo de contenido: `Proyecto`

La web pública todavía no consume contenido desde Sanity.
